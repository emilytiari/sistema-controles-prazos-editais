# SCPE — Sistema de Controle de Prazos de Editais

Versão demonstrativa para portfólio do SCPE, sistema desenvolvido para acompanhar prazos, etapas e responsáveis em processos de editais.

## Sobre esta versão

Este repositório foi criado a partir de uma base limpa, sem histórico do projeto original e sem conexão com o ambiente real.

- não contém chaves de API reais;
- não acessa o Supabase de produção;
- não envia e-mails, SMS ou WhatsApp;
- usa somente dados fictícios;
- ações como avançar ou arquivar são simuladas localmente.

## Funcionalidades demonstradas

- login demonstrativo;
- painel de editais;
- editais em andamento;
- editais concluídos;
- editais arquivados;
- acompanhamento de etapa atual;
- progresso do fluxo;
- avanço de etapa simulado;
- arquivamento simulado;
- visão responsiva para desktop e telas menores.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

O projeto original também utilizou Supabase e integrações de comunicação, mas essas dependências foram intencionalmente removidas desta versão pública de demonstração.

## Executando localmente

```bash
npm install
npm run dev
```

Depois, abra o endereço exibido pelo Vite no navegador.

## Segurança

Nunca adicione credenciais reais, arquivos `.env`, tokens ou chaves privadas neste repositório.
